Git

📄️git command

紀錄常見的 Git 指令：

📄️git fetch

在剛開始學 git 的時候，只知道 git fetch 是把檔案抓下來，git merge 是合併到本地端，當學到 git pull 時，得知

📄️git rebase

一般在合併分支時，比較常見的方式是使用 git merge，在看 git graph 的時候也比較容易看出分支的合併情況。不過當分支越來越多時，git graph 會變得越來越複雜，有些人反而喜歡分支乾淨一點，因此有另外一種合併分支的方式，那就是使用 git rebase。

📄️git tag

Git tag 是一個平常不太會用到的功能，基本上每次要使用時都要再看一次指令介紹，所以這邊就來整理一下。

📄️git worktree

在開發的時候，如果臨時要切換到其他分支去修復 Bug，不知道大家都會怎麼做？

📄️刪除未在遠端的本地端分支

在發 MR 或 PR 時，如果沒有要保留分支，會勾選 Delete branch after merge，遠端分支就會刪除了，但本地端分支還是會存在。當越開越多分支時，本地端分支就會越來越多，整個 git graph 就會變的很難看。紀錄一下如何刪除所有未在遠端存在的本地端分支。
